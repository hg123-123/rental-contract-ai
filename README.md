# 合同审查AI助手

> 帮大学生看懂租房合同和劳动合同的AI工具。上传合同，AI逐条分析风险，告诉你"这条对你不利，可以这样谈"——基于真实法条，不编造。

**[🔗 立即试用](https://indirect-comparison-myth-brochures.trycloudflare.com/chat/9BZCDRMElRGp2k7f)**

---

## 💡 为什么做这个

大学生签租房合同和劳动合同时，99%的人看不懂条款里的门道。现有方案都很糟：

- 📱 小红书搜帖 → 碎片化，不针对自己的合同
- 👨‍👩‍👦 问父母/学长 → 不一定懂
- 🔍 百度查法条 → 法律术语看不懂

**合同审查助手做的事**：上传合同 → AI基于真实法律条文分析 → 告诉你每条的风险 + 怎么跟房东/HR谈。

---

## 🧠 技术亮点

| 模块 | 选型 | 为什么 |
|---|---|---|
| 架构 | RAG（检索增强生成） | 法条原文锁定在知识库，LLM只负责解释 → 杜绝幻觉 |
| 生成模型 | DeepSeek-V4-Pro | 中文法律文本理解优秀，成本低 |
| 向量检索 | 通义千问 text-embedding-v3 | 中文语义匹配准，免费额度够用 |
| 平台 | Dify + Cloudflare Tunnel | 零前端开发，5天从0到MVP |

**知识库规模**：22份精编文档，覆盖民法典租赁章节、劳动合同法、杭州地方条例、30+真实风险点。
