# 杭州就业政策与人才补贴

## 应届生生活补贴

杭州市对来杭工作的应届毕业生发放生活补贴：
- 本科：1万元（分两次发放，每次5000元）
- 硕士：3万元
- 博士：10万元

申请条件：在杭州用人单位就业或自主创业，按规定缴纳社保，即可通过"亲清在线"或"杭州市民卡"APP申请。

## 应届生租房补贴

杭州市对来杭工作的应届毕业生发放租房补贴：
- 每年1万元，可连续领取3年（共3万元）
- 申请条件：在杭州无自有住房，通过租房备案或人才公寓入住

注意：租房补贴与生活补贴可同时申请。但租房补贴需要租赁备案证明，这就是为什么你会需要"租房备案"相关知识。

## 杭州市人才分类与待遇

- E类人才：博士/正高职称/杭州市级领军人才 → 购房补贴最高40万
- F类人才：硕士/副高职称/杭州市高级人才 → 租房补贴+人才公寓优先
- G类人才：本科及以上/杭州市骨干人才 → 租房补贴每年1万

应届本科毕业生通常属于G类或F类（视学校、专业、就业单位而定），具体可在"杭州市民卡"APP查询。

## 杭州最低工资与社保

- 杭州市区月最低工资标准：约2490元/月
- 社保缴费基数下限：4812元/月（注意：即使工资低于这个数，也要按这个基数缴纳社保）
- 社保缴费基数上限：按上年度全省职工平均工资的300%确定

提醒：如果公司提出"工资少交社保，到手多拿钱"——这是违法的，而且会影响你的医保报销、养老金和各类补贴申领资格。社保不仅是你当下的保障，也关系到你在杭州落户、买房、子女入学的资格。
