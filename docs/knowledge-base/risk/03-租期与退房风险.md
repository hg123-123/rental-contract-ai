# 租期与退房规则风险点

## 风险：最短租期不接受短租

暑假工通常只需要租2个月，但很多房东/中介要求最少签半年或一年合同，声称"公司规定"。签长期合同后提前退租，押金大概率被扣。

谈判建议：直接找接受短租的房源（可在租房平台筛选"可短租"标签）。如果看好一套房但房东不接受短租，可以提出"租金适当上浮10-15%换取2个月租期"，或主动提出"到期后我负责找下家转租"。

常见套路：中介说"你先签一年，到时候帮你转租"——转租权掌握在房东手里，他说不同意你就违约。

## 风险：提前退租条款写成"押金不退+违约金"

合同同时写"提前退租押金不退"和"提前退租需支付1个月违约金"——这是双重扣款，你损失2个月租金。

谈判建议：要求明确"提前退租属于违约，按违约金条款处理，押金在扣除违约金和合理费用后退还"。违约金上限建议不超过1个月租金。

常见套路：房东说"这是格式合同，改不了"——格式合同加重对方责任的条款无效，你可以要求修改，不改就不签。

## 风险：口头承诺短租/退押金，不写进合同

看房时房东满口答应"住两个月就行，到时候押金全退"，但合同里写的是"租期一年，提前退租押金不退"。发生纠纷时，法院只认合同。

谈判建议：所有承诺必须白纸黑字写进合同。如果房东拒绝修改合同，至少保留微信/短信聊天记录，并注明"以上内容与合同不一致时以本约定为准"。

常见套路："咱们都是实在人，不用写那么细"——不写细就是为了到时候不认账。
