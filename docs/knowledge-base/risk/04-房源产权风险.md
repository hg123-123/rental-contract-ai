# 房源产权与房东身份风险点

## 风险：二房东无原房东转租授权书

二房东（从原房东手里租房再转租给你）如果没有原房东的书面同意，原房东有权随时解除合同，你被清退后只能找二房东追偿——但二房东往往已经跑路或没钱。

谈判建议：必须查看二房东与原房东的租赁合同，确认其中有"允许转租"条款，或要求出示原房东签字的《同意转租证明》。最好能与原房东直接通话确认。

常见套路：二房东说"原房东在外地，不方便联系"或"我跟原房东合作很多年了，你放心"——没有书面授权就是定时炸弹。

## 风险：无法出示房产证原件

房东只给你看房产证照片或复印件，无法出示原件。可能是假证、已抵押房产、或者他根本不是产权人。

谈判建议：要求查看房产证原件，核对产权人姓名与房东身份证是否一致。如果是代理人，要求出示公证委托书。可以在"浙里办"APP查询房产登记信息核验真伪。

常见套路："房产证在老家/在银行抵押/还没办下来"——任何理由都不成立，看不到原件就不签约、不交钱。

## 风险：黑中介冒充房东签约

中介以"房东委托我全权处理"为由跟你签约，收完钱后消失，真正的房东找上门说你非法占用房屋。

谈判建议：签约时必须确认签约方是产权人本人。如果是中介代签，要求出示产权人的公证委托书，并直接与产权人电话/视频确认。

常见套路：中介在合同上签自己的名字，但没有任何授权文件——这种合同对产权人没有约束力，你被赶走后中介早已失联。
