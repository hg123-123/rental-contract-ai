# 配套设施与维修责任风险点

## 风险：维修责任归属模糊

合同只写"正常使用损坏由租客负责维修"，但不界定什么是"正常使用"。空调用三年坏了，是自然老化还是使用不当？灯泡烧了算谁的？

谈判建议：要求合同明确"家电家具因自然老化或正常使用损坏的，由房东负责维修或更换；因人为损坏（如故意破坏、不当操作）的，由租客承担维修费用"。

常见套路：入住时家电已经老旧，退租时房东说"都是你住坏的"，让你赔全新家电。

## 风险：入住前未拍照/录像留证

入住时墙面已经有裂缝、地板有划痕、灯泡是坏的，但因为没有证据，退租时房东说是你造成的，从押金里扣款。

谈判建议：入住当天全程录像（从进门开始，每个房间、每件家具、每个墙面细节），照片带时间水印，发送给房东微信确认"以上为我入住时的房屋现状，双方确认无异议"。

常见套路：房东说"不用那么麻烦，我信得过你"——信得过你，但信不过你的押金。

## 风险：家电未当场测试

签约时没试空调制冷、热水器出热水、洗衣机排水，入住后发现坏的，房东说是你弄坏的，要求你修或赔。

谈判建议：签约前要求当场测试所有家电功能，有问题要求房东维修后再签约，或在合同中列明"以下家电已有损坏/故障：____，由房东负责在X日内维修"。

常见套路："这个空调之前好好的，怎么你一住就坏了"——无法证明入住时就是坏的，只能吃哑巴亏。
