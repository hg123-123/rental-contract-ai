# 看房实操与预算规划风险点

## 风险：房租超过月收入/生活费的1/3

刚毕业或暑假工收入有限，如果房租占比过高，会导致生活质量严重下降，甚至需要借钱交租。

谈判建议：设定硬预算线（如每月房租+水电不超过1500元），超预算的房子直接pass，不要幻想"省省就过去了"。

常见套路：中介带你先看超出预算的好房子，再看预算内的差房子，让你觉得"加几百块住好点值得"——这是锚定效应，坚持预算。

## 风险：忽视通勤成本

为了便宜租到远郊，结果每天通勤2小时，地铁费每月300+，时间成本更是无法计算。

谈判建议：计算"房租+通勤费+时间成本"的总成本。有时候市中心贵500元的房子，比远郊便宜500元的房子实际成本更低。

常见套路："这个房子离地铁就一站公交"——实际公交20分钟一班，下雨天根本打不到车。

## 风险：只看一次房就签约

白天看房时光线好、邻居安静、周边整洁，但晚上可能有夜市噪音、工地施工、小区安保松懈等问题。

谈判建议：至少看房两次——白天看采光和周边配套，晚上8-10点看噪音和安保。如果条件允许，雨天再看一次是否漏水渗水。

常见套路：中介只安排白天看房，说"晚上房东不方便"——不方便的可能不是房东，而是怕你发现问题。

## 风险：忽视隔音效果

合租房或公寓隔音差，隔壁说话、楼上走路都听得一清二楚，严重影响休息。

谈判建议：看房时让中介或房东在隔壁房间说话/走动，你在目标房间听隔音效果。尤其是隔断房（用石膏板隔出来的房间），隔音几乎为零，直接pass。

常见套路：房东说"这个墙是实心的"——敲一敲就知道，实心墙声音沉闷，空心墙/石膏板声音空洞。

## 风险：未检查潮湿/霉斑问题

房间阴暗潮湿，墙面有霉斑，住久了不仅影响心情，还可能引发呼吸道疾病。

谈判建议：用手摸墙面是否有潮湿感，闻房间是否有霉味，检查墙角、窗台下是否有黑色霉斑。有霉斑的房间直接pass，因为霉菌很难根治。

常见套路：房东说"就是有点潮，买个除湿机就好了"——除湿机只能缓解，不能解决结构性潮湿问题。
