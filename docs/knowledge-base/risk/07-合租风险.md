# 合租室友相关风险点

## 风险：与陌生人合租未提前了解生活习惯

室友半夜吵闹、不打扫卫生、带异性回来过夜、占用公共空间，导致居住体验极差。

谈判建议：合租前必须与室友面谈，了解彼此作息、卫生习惯、是否养宠物、是否常带朋友回来。最好找同学/朋友合租，或通过正规平台筛选有实名认证的室友。

常见套路：中介说"室友都是年轻人，很好相处的"——好不好相处要你自己判断，中介只管成交不管售后。

## 风险：合租公共区域责任不清

厨房、卫生间、客厅谁打扫？水电费按人头还是按房间分摊？带朋友回来需不需要提前说？

谈判建议：入住前与室友书面约定公共规则（哪怕是一张简单的合租公约），避免日后扯皮。

常见套路："都是小事，住一起慢慢磨合"——小事积累起来就是矛盾爆发点。
