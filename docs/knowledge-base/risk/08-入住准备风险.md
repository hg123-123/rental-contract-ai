# 入住准备相关风险点

## 风险：未换门锁/未检查前任租客钥匙

前任租客、中介、房东手里都可能有钥匙，独居女生安全风险极高。

谈判建议：入住当天立即更换门锁（或加装智能门锁），费用100-300元，远低于安全事件的成本。

常见套路：房东说"钥匙都收回来了，放心"——你无法确认他是否收了全部钥匙，换锁是最保险的做法。

## 风险：未办理水电燃气过户/未核对初始读数

沿用前任租户的账户，可能导致你替他缴欠费；或者房东代缴后虚报读数多收钱。

谈判建议：入住当天拍照记录水电燃气表读数，要求房东结清前任租客费用。尽量自己办理缴费账户，避免房东中间赚差价。

常见套路："水电费我统一收，月底给你账单"——账单可能造假，自己缴费最透明。

## 风险：未熟悉周边生活配套

入住后才发现最近的外卖要1小时送达、最近的超市在2公里外、快递驿站晚上8点就关门。

谈判建议：看房时打开外卖APP查看配送范围和时长，步行查看周边500米内是否有超市、药店、快递点、早餐店。

常见套路：中介说"周边配套很成熟"——他可能指的是3公里外有商场，不是你每天需要的生活便利。
