# 合同审查AI助手 设计说明（修订版）

## 背景与目标

### 问题描述
大学生外出求职面临两类合同——租房合同和劳动合同，绝大多数人对合同条款中的门道一无所知。当前他们的解决方案存在明显缺陷：

| 当前做法 | 痛点 |
|---|---|
| 小红书/抖音搜避坑帖 | 碎片化、不针对具体合同、无法验证可靠性 |
| 问父母/学长学姐 | 不一定懂、不好意思频繁询问 |
| 百度/知乎查法条 | 看不懂法律术语、不知道哪条适用于自己的情况 |

### 目标
打造一个 AI 驱动的合同辅助阅读工具，覆盖租房合同和劳动合同，帮助大学生：
- 看懂合同条款的真实含义
- 识别条款中对乙方不利的风险点
- 获得基于真实法条和风险经验的分析结果
- 在签约前做出更明智的决策

## MVP 方案（经实践验证后的最终形态）

### 平台选择

经过微信小程序、H5 自建前端、GitHub Pages、Vercel、Cloudflare Pages 等多轮尝试，最终确定：

**使用 Dify 自带的聊天助手页面作为 MVP 交付物。** 理由：
- 零前端开发：Dify 自带美观的聊天界面
- 原生多轮记忆：不需要自己管理 conversation_id
- 知识库直接挂接：法律、风险、劳动法三库联动
- 即刻可用：发布即得公开链接

### 用户画像
- **全部大学生群体**：大三/大四实习生（短租+实习合同）、应届毕业生（首次独立租房+首份劳动合同）
- **地域聚焦**：MVP 阶段限定杭州
- **获客方式**：小红书/抖音发避坑内容引流 → 分享 Dify 聊天链接

### 成功标准

| 指标 | 衡量什么 |
|---|---|
| 访问量 | 有多少人点开了链接 |
| 使用频率 | 是否有回头用户 |
| 用户反馈 | 是否有人主动说"有用" |

## 技术架构

```
用户浏览器（手机/电脑）
    │ HTTPS
    ▼
Cloudflare Tunnel（免费）
    │
    ▼
笔记本 Docker（Dify 自部署）
├── Chatflow / 聊天助手
├── 📚 法律知识库（房屋租赁+劳动合同相关法规）
├── ⚠️ 风险知识库（租房+劳动常见陷阱）
├── 💼 劳动法知识库
├── Embedding: 通义千问 text-embedding-v3
└── 生成模型: DeepSeek-V4-Pro
```

## 知识库（三大板块）

### 一、法律知识库（租赁法规）
6 份文档，涵盖《民法典》租赁章节、住建部管理办法、杭州+浙江地方条例、押金专题等。

### 二、风险知识库（租房避坑）
8 份文档，30+ 风险点，覆盖押金、租金费用、违约金、维修责任、转租退租、房源产权、看房预算、合租入住各个环节。

### 三、劳动法知识库
8 份文档，涵盖《劳动合同法》核心条款、《劳动法》工时与加班、社保与公积金、加班费计算、年假工伤辞退保护、杭州就业政策与人才补贴、劳动合同避坑实战指南。

## 部署依赖

| 条件 | 说明 |
|---|---|
| 笔记本开机 | Dify Docker 运行在笔记本上 |
| Cloudflare Tunnel | 将 Dify 暴露至公网 |
| 链接有效期 | Tunnel 重启后链接中的域名会变，需更新 |

## 限制与后续规划

| 限制 | 后续方案 |
|---|---|
| Tunnel 重启后链接失效 | 买云服务器 ¥68-200/月，彻底稳定 |
| 没有独立品牌页面 | 后续可做简单的落地页 |
| Dify 页面无法定制 | 后续用 Chatflow 或自建前端替代 |
| 无法追踪用户行为 | Dify 自带日志可查看使用量 |
