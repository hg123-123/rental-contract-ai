# 产品路线图：合同审查AI助手

## 当前阶段：MVP验证（2026年7月）

**交付物**：Dify聊天助手 + 3个知识库（22份文档） + Cloudflare Tunnel

**目标**：
- [ ] 找5-10个真实用户试用
- [ ] 收集首次使用反馈（有用/没用/缺什么）
- [ ] 确认用户是否愿意推荐给同学

---

## V1.0：稳定上线（预计2周）

**触发条件**：有用户反馈"有用"，或日访问超过5人

| 优先级 | 事项 | 说明 |
|---|---|---|
| P0 | 云服务器迁移 | 阿里云ECS ¥68-200/月，告别Tunnel不稳定的问题 |
| P0 | 固定域名 | 购买域名 + 配置HTTPS |
| P1 | Dify升级到稳定版 | 等1.16正式版发布后再迁移 |
| P1 | 系统提示词优化 | 根据用户反馈调整措辞和理解能力 |
| P2 | 添加使用引导 | 首次打开显示"我可以帮你做什么" |

---

## V1.1：体验优化（预计2周）

| 优先级 | 事项 | 说明 |
|---|---|---|
| P1 | 多城市法律覆盖 | 北京/上海/深圳地方租赁管理条例 |
| P1 | 劳动法知识库扩充 | 补充竞业限制判例、裁员补偿计算器 |
| P2 | 输出格式优化 | 合同分析时用结构化表格呈现风险点 |
| P2 | 文件上传支持优化 | 支持PDF直接上传（目前仅图片和文本） |
| P3 | 使用数据看板 | Dify日志分析：访问量、高频问题、检索失败case |

---

## V2.0：独立产品（预计1-2个月）

| 优先级 | 事项 | 说明 |
|---|---|---|
| P0 | 独立品牌落地页 | 一句话介绍 + 截图 + 试用入口 |
| P1 | 微信小程序 | 如果用户反馈需要。需解决类目审核问题 |
| P1 | H5移动端页面 | React前端项目恢复开发，挂载到云服务器 |
| P1 | 合同分析专用模式 | 上传合同→自动生成风险报告（PDF可下载） |
| P2 | 账户系统 | 微信/手机号登录，保存历史分析记录 |
| P2 | 分享裂变 | 分析结果生成分享卡片，附带邀请链接 |

---

## V3.0：商业化（按需启动）

**触发条件**：日活超过100人或收到付费意愿反馈

| 优先级 | 事项 | 说明 |
|---|---|---|
| P1 | 免费增值模式 | 每天3次免费分析，深度报告收费 |
| P1 | 付费方案 | ¥9.9/次详析 或 ¥29.9/月无限次 |
| P2 | B端方向探索 | 高校就业指导中心合作、租房平台API对接 |
| P3 | 律师人工复核 | 高风险合同可选人工律师复核（渠道合作） |

---

## 持续积累（贯穿所有阶段）

- **知识库维护**：每周根据用户反馈补充新的风险点和法条
- **Prompt迭代**：每周review用户对话记录，优化系统提示词
- **用户访谈**：每月访谈3-5个活跃用户
